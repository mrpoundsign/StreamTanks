STEP-BY-STEP SETUP

Up and Running in Under 3 Minutes

StreamTanks compiles into a single, self-contained executable with embedded SQLite and embedded web assets. Zero external dependencies or Node.js runtime required.

1

Download StreamTanks

Grab the latest release archive for your operating system from the Releases page:

🪟 Windows (x64) 🐧 Linux (amd64 / arm64) 🍎 macOS (Apple Silicon / Intel)

Extract the zip into a folder of your choice (e.g. C:\StreamTanks\ on Windows or ~/StreamTanks/ on Linux/macOS).

2

Launch the Server

Start StreamTanks on your machine. No configuration files required to start:

Windows 
# Double-click StreamTanks.exe, or run in terminal:
.\StreamTanks.exe
macOS / Linux 
chmod +x StreamTanks
./StreamTanks
⚙️ Optional CLI Flags:
  • -addr :8102 — Customize the local HTTP/WebSocket port (default: :8102).
  • -channel <name> — Set the target Twitch channel directly via terminal flag.
  • -debug — Launches in local offline testing mode with an on-screen debug command bar and target practice bot.
💡 Pro-Tip: Offline Debug Testing

Want to test aiming, crater deformation, and tank physics without going live on Twitch? Launch with -debug:

Debug Run 
.\StreamTanks.exe -debug
BROADCAST OVERLAY

Add to OBS Studio

StreamTanks serves a transparent, high-performance 1920x1080 HTML5 canvas overlay directly over local HTTP. Your webcam and stream game show through cleanly behind the neon battlefield.

3

Configure OBS Browser Source

Follow these steps in OBS Studio to add the overlay to your stream scene:

  1. Open OBS Studio and select your desired streaming scene.
  2. Under the Sources dock, click + (Add) and select Browser.
  3. Name it StreamTanks and configure the properties:
    • URL: http://localhost:8102
    • Width: 1920
    • Height: 1080
    • Shutdown source when not visible: Checked (recommended)
    • Refresh browser when scene becomes active: Checked (recommended)
  4. Click OK. The transparent battlefield will now render cleanly over your stream!
🛡️ Disconnect Resilience

The overlay automatically detects server restarts or disconnects. If the game server restarts, the overlay becomes 100% transparent so your stream never shows an ugly "connection failed" browser error, and automatically reloads once the server is back online!

TWITCH INTEGRATION

Link Your Twitch Channel

Connect the local game engine to your Twitch channel so chat commands and viewers are automatically routed to your battlefield.

4

Authorize via Commander Admin Console

⭐ RECOMMENDED

The easiest way to connect your channel is through the built-in Commander Admin Console:

  1. Open http://localhost:8102/admin in your web browser (or dock it inside OBS Studio as a Custom Browser Dock).
  2. In the top header, locate the Channel: None (Local) pill and click Set.
  3. Enter your Twitch channel name (e.g. mrpoundsign) and click Save. You will receive a unique one-time claim command (e.g. %claim PU5HZX).
  4. Type or paste the %claim <CODE> command into your Twitch chat as the streamer to link and authorize your channel!

Once verified, StreamTanks securely saves your host authorization token and channel in the embedded SQLite database so you never have to re-enter or re-authorize it on future launches.

Twitch Chat Claim Example 
# Type in your channel chat as the streamer:
%claim PU5HZX

STREAMER COMMAND CODEX

Streamer & Moderator Chat Commands

All commands default to the % prefix (customizable via %prefix). Streamers can also run all of these commands from the Admin Console terminal.

Command Arguments Role Description Action
%startgame - Streamer Starts an artillery match from the IDLE waiting phase. (Streamer by default; permission configurable via %perm start <role>).
%roundtime <seconds> Streamer/Mod Configures the input phase countdown duration (range: 5s to 120s, default: 20s).
%autoround <minutes|-1|off> Streamer/Mod Automates round starts: -1 for immediate new round, >0 for scheduled minutes, or off.
%idlemessage [on|off] Streamer/Mod Toggles visibility of the idle countdown message and persistent leaderboard during waiting phase.
%speed <0.1 - 3.0> Streamer/Mod Adjusts physics and projectile simulation speed (default: 0.5x).
%bouncywalls [on|off] Streamer/Mod Toggles screen-edge bouncy walls (+10% bullet speed, +50% tank speed).
%terrain <min%> <max%> Streamer/Mod Sets vertical screen height percentage bounds for procedural hills, or %terrain reset.
%terraincolor <hex|preset> Streamer/Mod Customizes neon terrain outline glow and subtle ground fill (presets: red, cyan, green, purple, orange, yellow, white, or hex e.g. #00ffcc; %terraincolor reset for default).
%terrainclimb [on|off] Streamer/Mod Toggles whether tanks can scale steep cliffs and crater walls (default: off / blocked).
%tankcolor <hex|preset> Streamer/Mod Customizes neon tank tread outline glow (presets: red, cyan, green, purple, orange, yellow, white, or hex e.g. #00ffcc; %tankcolor reset for default).
%minplayers <2 - 20> Streamer/Mod Sets minimum player threshold to auto-fill with bot combatants (default: 5).
%botfill [on|off] Streamer/Mod Toggles automatic bot filling up to the minimum player threshold (default: on).
%botpoints <0 - 10> Streamer/Mod Configures leaderboard points awarded to human players for destroying an AI bot (default: 1).
%botlist <add|remove|list> [name] Streamer/Mod Manages the custom pool of named AI bot combatants stored in SQLite.
%channel <name|off> Streamer Sets the target Twitch channel, or switches to offline mode with off.
%claim <code> Streamer Authorizes and links your local game host to your Twitch channel via one-time challenge code.
%prefix <str> Streamer Customizes the command prefix for all chat triggers (e.g. ! or $).
%perm <start|config> <role> Streamer Configures role permissions for starting games or modifying settings. Accepted role parameters: broadcaster (streamer), mod, vip, sub, or all.
%kick <username> Streamer/Mod Immediately removes a player from the active match, despawning their tank and projectiles.
%deleteplayer <username> Streamer/Mod Removes player entirely from the persistent SQLite leaderboard and active match.
%clearleaderboard - Streamer Resets all player win stats in the SQLite database and connected overlays.

STREAMER TROUBLESHOOTING

Frequently Asked Streamer Questions

How do I test the game before going live?

Launch StreamTanks with the -debug flag (e.g. .\StreamTanks.exe -debug). This enables an on-screen debug bar at the bottom of the OBS overlay and spawns a target practice bot so you can test firing and craters immediately without connecting to Twitch.

Do I need to configure router port forwarding?

No! StreamTanks serves the OBS browser source locally (http://localhost:8102). When using Twitch chat or the Twitch Extension cloud relay, StreamTanks makes an outbound connection to Twitch and our C&C relay, requiring zero port forwarding.

What happens if StreamTanks restarts during my stream?

The frontend overlay automatically detects disconnects, becomes completely transparent so your stream never shows a broken browser page, continuously polls, and reloads automatically once the server is back online.

Where are my settings and leaderboard saved?

All settings, channels, permissions, bot rosters, and leaderboard scores are stored locally in an embedded SQLite database file (streamtanks.db) in your working directory. Back up this file to preserve your leaderboard across updates.
