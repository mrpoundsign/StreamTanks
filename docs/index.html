STREAMER SETUP

Up and Running in Under 3 Minutes

StreamTanks compiles into a single, self-contained executable with embedded SQLite and embedded web assets. No databases to configure, no Node.js runtime required.

1

Download StreamTanks

Grab the latest release archive for your operating system from the Releases page:

🪟 Windows (x64) 🐧 Linux (amd64 / arm64) 🍎 macOS (Apple Silicon / Intel)

Extract the zip into a folder of your choice (e.g. C:\StreamTanks\).

2

Launch StreamTanks

Start StreamTanks on your machine. No complex setup or installation required:

Windows 
# Double-click StreamTanks.exe, or run in terminal:
.\StreamTanks.exe
macOS / Linux 
chmod +x StreamTanks
./StreamTanks
💡 Pro-Tip: Offline Debug Mode

Want to test without going live or connecting to Twitch? Launch with -debug to spawn an on-screen debug command bar and a practice bot target:

Debug Run 
.\StreamTanks.exe -debug
3

Connect from the Admin Console

⭐ RECOMMENDED

The recommended way to connect your Twitch channel is directly through the Commander Admin Console:

  1. Open http://localhost:8102/admin in your browser (or dock it in OBS as a Custom Browser Dock).
  2. In the top header, locate the Channel: None (Local) pill and click Set.
  3. Enter your Twitch channel name (e.g. mrpoundsign) and click Save. You are given the %claim <CODE> command to link your channel (displayed in an authorization banner and in your terminal logs).
  4. Type or paste the %claim <CODE> command into your Twitch chat as the broadcaster to link and authorize your channel!

Once verified, StreamTanks securely saves your host authorization token and channel in the embedded SQLite database so you never have to re-enter or re-authorize it on future launches.

Terminal Alternative:

Prefer passing it as a flag? You can also launch with .\StreamTanks.exe -channel your_channel_name.

4

Add to OBS Studio

StreamTanks serves a transparent, high-performance HTML5 canvas overlay over local HTTP:

  1. Open OBS Studio and navigate to your main scene.
  2. Under Sources, click + and select Browser.
  3. Set the Browser Source properties:
    • URL: http://localhost:8102
    • Width: 1920
    • Height: 1080
    • Shutdown source when not visible: Checked (recommended)
    • Refresh browser when scene becomes active: Checked (recommended)
  4. Click OK. The transparent battlefield will now render seamlessly over your stream gameplay or camera!

REFERENCE GUIDE

Twitch Chat Command Codex

All commands default to the % prefix (fully customizable via %prefix). Click any copy button to paste straight into chat or OBS.

Command Arguments Role Description Action
%join [emote] All Joins the active battlefield. Optionally provide a Twitch channel emote name.
%fire <angle> <power> All Locks in cannon angle (0° to 180°) and power (1 to 100). Omitting values uses last aim.
%left - All Maneuvers your tank to the left across the neon terrain hills.
%right - All Maneuvers your tank to the right across the neon terrain hills.
%icon <emote> All Changes or updates your tank's emote icon. Automatically saves and persists across matches. (Aliases: %emote, %skin).
%shield - All Activates your tactical one-time energy shield for the current match to absorb crater blasts and direct hits.
%leave - All Leaves the active match or waiting lobby immediately.
%startgame - Streamer/Mod Starts an artillery match from the IDLE waiting phase. (Role configurable).
%channel <name|off> Broadcaster Sets the target Twitch channel, or switches to offline mode with off.
%claim <code> Broadcaster Authorizes and links your local game host to your Twitch channel via one-time challenge code.
%prefix <str> Broadcaster Customizes the command prefix for all chat triggers (e.g. ! or $).
%roundtime <seconds> Streamer/Mod Configures the input phase countdown duration (range: 5s to 120s, default: 20s).
%speed <0.1 - 3.0> Streamer/Mod Adjusts physics and projectile simulation speed (default: 0.5x).
%autoround <minutes|-1|off> Streamer/Mod Automates round starts: -1 for immediate, >0 minutes, or off.
%bouncywalls [on|off] Streamer/Mod Toggles screen-edge bouncy walls (+10% bullet speed, +50% tank speed).
%idlemessage [on|off] Streamer/Mod Toggles visibility of the idle countdown message and persistent leaderboard.
%terrain <min%> <max%> Streamer/Mod Sets height percentage bounds for procedural hills, or %terrain reset.
%kick <username> Streamer/Mod Immediately removes a player from active match, despawning their tank and shells.
%deleteplayer <username> Streamer/Mod Removes player entirely from persistent SQLite leaderboard and active match.
%clearleaderboard - Broadcaster Resets all player win stats in the SQLite database and connected overlays.
%perm <start|config> <role> Broadcaster Configures permissions: broadcaster, mod, vip, sub, or all.
%minplayers <2 - 20> Streamer/Mod Sets minimum player threshold to auto-fill with bot opponents (default: 5).
%botfill [on|off] Streamer/Mod Toggles automatic bot filling up to the minimum player threshold (default: on).
%botpoints <0 - 10> Streamer/Mod Configures leaderboard points awarded to humans for destroying an AI bot (default: 1).
%botlist <add|remove|list> [name] Streamer/Mod Manages the custom pool of named AI bot combatants in the database.

FREQUENTLY ASKED QUESTIONS

Common Questions & Troubleshooting

Is StreamTanks free and open source?

Yes! StreamTanks is 100% free and open-source software licensed under the GNU Affero General Public License v3.0 (AGPL-3.0).

Does StreamTanks require a database server or runtime?

No. StreamTanks is a single compiled Go binary with an embedded SQLite database engine. There are zero external dependencies or database daemons to configure.

How can I test the game when I'm not streaming?

Launch StreamTanks with the -debug flag. This enables an on-screen debug bar at the bottom of the overlay and spawns a target bot so you can test firing immediately.

What happens if my server restarts or crashes during a stream?

The frontend overlay automatically detects disconnects, becomes completely transparent so your stream never shows a broken browser page, continuously polls, and reloads automatically once the server is back up.
